# EduAI — To'liq AI Ta'lim Platformasi

## Papkalar tuzilmasi
- `schema.sql` — Supabase PostgreSQL jadvallari
- `eduai-backend/` — Node.js + Express + Gemini API + Supabase + Google Admin Auth serveri
- `eduai-client/` — React + Vite + Tailwind CSS v4 frontend ilovasi

## Ishga tushirish
1. `eduai-backend/.env.example` faylidan nusxa olib `.env` yarating va kalitlaringizni yozing.
2. `eduai-backend` ichida: `npm install && npm start`
3. `eduai-client/.env.example` faylidan nusxa olib `.env` yarating.
4. `eduai-client` ichida: `npm install && npm run dev`
